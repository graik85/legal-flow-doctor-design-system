# Badge

Compact inline label for status, counts, and categories. Use on case list rows, table cells, and sidebar counts.

```jsx
<Badge variant="active" dot>Active</Badge>
<Badge variant="urgent" dot>Urgent</Badge>
<Badge variant="pending">Awaiting Signature</Badge>
<Badge variant="gold" size="sm">Premium</Badge>
```

**Variants:** `default` · `active` (green) · `pending` (amber) · `closed` (gray) · `review` (blue) · `urgent` (red) · `teal` · `navy` · `gold`

Use `dot={true}` to add a colored indicator dot before the label text.
